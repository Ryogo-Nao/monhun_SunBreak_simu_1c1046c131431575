# MH手持ち装備シミュ（サンブレイク／ワイルズ）

**手持ちの装備を登録して使える**モンスターハンターのスキルシミュレータです。設定画面でゲームタイトルを切り替えて使います。

| タイトル | 個体ごとに性能が違う装備（登録して使う） |
| --- | --- |
| モンスターハンターライズ：サンブレイク | 傀異錬成防具、護石、武器（スロット） |
| モンスターハンターワイルズ | アーティア武器（付与スキル・スロット）、光るお守り（鑑定護石・武器/防具スロット） |

ビルド不要の静的Webアプリなので、GitHub Pages に置くだけでスマホ（iPhone）・PCのブラウザから使えます。

## 機能

| 機能 | 内容 |
| --- | --- |
| タイトル切替 | 設定 →「ゲームタイトル」で サンブレイク／ワイルズ を選択。手持ちデータ・条件・マイセットはタイトルごとに別保存 |
| 装備の登録・管理 | 防具（ワイルズは武器・固定護石も）の所持登録／除外、傀異錬成防具・アーティア武器・護石の登録・編集・複製・削除、装飾品の所持数 |
| 傀異錬成（SB） | ベース防具を選び、錬成後スロット・スキルの増減（マイナスも可）・防御/耐性の増減を登録 |
| アーティア（ワイルズ） | 武器種・グループスキル・シリーズスキル（各1部位分）・武器スロットを登録 |
| 光るお守り（ワイルズ） | スキル3つまで＋スロットごとに「武器用／防具用」を指定して登録 |
| スキル条件 | スキルとLvを選択（名前の一部・読み・飛び飛びの入力で検索可。例: 「弱特」「こうげき」「研磨術鋭」）。**必須**の指定は数の制限なし。並び順＝優先度（↑↓で変更）。ワイルズのシリーズ／グループスキルは発動段階（例: 力自慢Ⅱ＝4部位）で指定 |
| 優先度 | 必須スキルは必ず満たし、希望（必須でない）スキルは優先度の高いものから順に満たすよう装飾品を割り当て |
| 全組み合わせ表示 | 条件を満たす組み合わせを列挙（最大件数は500〜100,000件で選択）。同じ性能の装備は「同等装備」としてまとめて表示 |
| ソート | 検索結果・防具・傀異錬成/アーティア・護石・武器・装飾品・マイセットの全画面で並び替え可（空きスロット数/合計Lv、武器/防具スロット別、防御力、耐性、任意スキルのLv など） |
| 未所持装備の切替 | 「所持していない…も対象にする」スイッチで、所持登録した装備だけ／全装備を切り替え |
| マイセット | 気に入った結果を保存・メモ |
| インポート | 泣きシミュ形式の護石・傀異錬成（SB）／光るお守り（ワイルズ）CSVを貼り付けで一括登録 |
| バックアップ | JSONファイル／テキストで保存・復元（PC⇔スマホのデータ移行にも） |
| スマホ対応 | iPhone 15 Plus 幅で確認済み。ホーム画面に追加するとアプリのように起動（オフライン動作） |

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main`（または作業ブランチ）に push すると `.github/workflows/pages.yml` がテスト後に自動デプロイ
3. 表示されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

> ※ Pages の `github-pages` 環境はデフォルトでは既定ブランチからのデプロイのみ許可されています。作業ブランチから出す場合は Settings → Environments → github-pages でブランチを許可してください。

ローカルで試す場合:

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます（`file://` では Web Worker が動かないため HTTP サーバー経由で開いてください）。

## 使い方

1. **設定タブ**でゲームタイトルを選択
2. **装備タブ**で手持ちを登録
   - 防具（ワイルズは武器・固定護石も）: 「所持」をON（「表示中をすべて所持にする」で一括も可）。使いたくない防具は「除外」
   - サンブレイク: 防具一覧の「＋傀異錬成として登録」→ 錬成後のスロットとスキル変化を入力
   - ワイルズ: 「アーティア」タブでアーティア武器、「護石」タブで光るお守りを登録
3. **検索タブ**でスキルを追加 → Lv・必須/希望・優先度（↑↓）を設定。ワイルズは武器種と武器の選び方（武器種の中から探す／特定の武器・アーティア／スロット直接指定）も選択 →「この条件で検索」
4. **結果タブ**で並び替え・絞り込み。「⭐保存」でマイセットへ

## 検索の仕組み

- 部位ごとに「条件スキルのポイント＋スロット構成」が同じ装備を1グループにまとめ、さらに（ONの場合）完全に劣る下位互換を除外してから全組み合わせを深さ優先探索します。
- 残り部位で得られる最大ポイント・最大スロットから「必須スキルを満たせる見込みがない」枝を刈り込みます。
- 各組み合わせで、スロットのサイズ制約（サイズk以上の装飾品数 ≦ サイズk以上のスロット数）を満たす装飾品の割り当てを探索し、必須スキルを満たしたうえで希望スキルを優先度順（辞書式）に最大化、同点なら空きスロットが多いものを採用します。
- ワイルズ対応:
  - スロットは「武器用」「防具用」を別々に扱い、武器用装飾品は武器用スロット（武器・光るお守りの武器スロット）にのみ装着します。
  - 2スキル付きの複合珠（例: 研磨・攻撃珠【３】）は、条件スキルへの寄与ごとにまとめて組み合わせを探索します。
  - シリーズ／グループスキルはポイント（部位数）で計算し、発動段階の閾値（例: 2部位／4部位）で判定します。
- 探索は Web Worker で行うため、検索中も画面は固まりません（中止ボタンあり）。

## データ

| タイトル | 出典 | 変換スクリプト | 出力 |
| --- | --- | --- | --- |
| サンブレイク | [RiseSim](https://github.com/EXXXI/RiseSim)（MIT, © 2022 EXXXI）Ver.16 対応CSV | `tools/convert.py` | `data/master.json` |
| ワイルズ | [WildsSim](https://github.com/EXXXI/WildsSim)（MIT, © 2025 EXXXI）2026/3/4 更新CSV | `tools/convert_wilds.py` | `data/wilds/master.json` |

- 元CSVとライセンスは `data/source/`・`data/wilds/source/` にあります。
- **データ更新（ワイルズのアップデート・大型拡張「アセンダンス」等）**: WildsSim の最新 `MHWilds_*.csv` を `data/wilds/source/` に上書きして `python3 tools/convert_wilds.py` を実行してください。拡張で新しい仕組み（例: 新たなランダム要素の装備）が増えた場合は、データだけでなくアプリ側の対応も必要になる可能性があります。
- 登録した手持ちデータはブラウザの localStorage に保存されます（端末ごと・タイトルごと。サーバーには送信されません）。

## 開発

```bash
npm test   # 探索エンジン（SB/ワイルズ）と検索のテスト（実データ使用）
```

| パス | 役割 |
| --- | --- |
| `index.html`, `css/style.css` | 画面 |
| `js/app.js` | UI（タイトル切替・登録・検索・結果・ソート） |
| `js/store.js` | 保存（タイトル別）・バックアップ |
| `js/solver.js` | 探索エンジン（UI非依存、SB/ワイルズ共通） |
| `js/search.js` | あいまい検索 |
| `js/worker.js` | 探索を Web Worker で実行 |
| `sw.js`, `manifest.webmanifest` | オフライン対応・ホーム画面追加 |
