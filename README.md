# サンブレイク 手持ち装備シミュ

モンスターハンターライズ：サンブレイク向けの、**手持ちの装備（傀異錬成防具・護石・武器・装飾品）を登録して使える**スキルシミュレータです。
ビルド不要の静的Webアプリなので、GitHub Pages に置くだけでスマホ（iPhone）・PCのブラウザから使えます。

## 機能

| 機能 | 内容 |
| --- | --- |
| 装備の登録・管理 | 防具の所持登録／検索対象からの除外、傀異錬成防具・護石・武器の登録・編集・複製・削除、装飾品の所持数 |
| 傀異錬成 | ベース防具を選び、錬成後スロット・スキルの増減（マイナスも可）・防御/耐性の増減を登録 |
| スキル条件 | スキルとLvを選択。**必須**の指定は数の制限なし。並び順＝優先度（↑↓で変更） |
| 優先度 | 必須スキルは必ず満たし、希望（必須でない）スキルは優先度の高いものから順に満たすよう装飾品を割り当て |
| 全組み合わせ表示 | 条件を満たす組み合わせを列挙（最大件数は500〜100,000件で選択）。同じ性能の装備は「同等装備」としてまとめて表示 |
| ソート | 検索結果・防具・傀異錬成・護石・武器・装飾品・マイセットの全画面で並び替え可（空きスロット数/合計Lv/Lv4空き、防御力、耐性、任意スキルのLv など） |
| 未所持装備の切替 | 「所持していない防具も対象にする」スイッチで、所持登録した防具だけ／全防具を切り替え |
| マイセット | 気に入った結果を保存・メモ |
| インポート | 泣きシミュ形式の護石・傀異錬成CSVを貼り付けで一括登録 |
| バックアップ | JSONファイル／テキストで保存・復元（PC⇔スマホのデータ移行にも） |
| スマホ対応 | iPhone 15 Plus 幅で確認済み。ホーム画面に追加するとアプリのように起動（オフライン動作） |

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main`（または作業ブランチ）に push すると `.github/workflows/pages.yml` がテスト後に自動デプロイ
3. 表示されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

> ※ Pages の `github-pages` 環境はデフォルトでは既定ブランチからのデプロイのみ許可されています。作業ブランチから出す場合は Settings → Environments → github-pages でブランチを許可してください。

ローカルで試す場合:

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます（`file://` では Web Worker が動かないため HTTP サーバー経由で開いてください）。

## 使い方

1. **装備タブ**で手持ちを登録
   - 防具: 「所持」をON（「表示中をすべて所持にする」で一括も可）。使いたくない防具は「除外」
   - 傀異錬成: 防具一覧の「＋傀異錬成として登録」→ 錬成後のスロットとスキル変化を入力
   - 護石・武器: 「＋登録」。護石は「続けて登録」で連続入力できます
2. **検索タブ**でスキルを追加 → Lv・必須/希望・優先度（↑↓）を設定 → 「この条件で検索」
3. **結果タブ**で並び替え・絞り込み。「⭐保存」でマイセットへ

## 検索の仕組み

- 部位ごとに「条件スキルのポイント＋スロット構成」が同じ装備を1グループにまとめ、さらに（ONの場合）完全に劣る下位互換を除外してから全組み合わせを深さ優先探索します。
- 残り部位で得られる最大ポイント・最大スロットから「必須スキルを満たせる見込みがない」枝を刈り込みます。
- 各組み合わせで、スロットのサイズ制約（サイズk以上の装飾品数 ≦ サイズk以上のスロット数）を満たす装飾品の割り当てを探索し、必須スキルを満たしたうえで希望スキルを優先度順（辞書式）に最大化、同点なら空きスロットが多いものを採用します。
- 探索は Web Worker で行うため、検索中も画面は固まりません（中止ボタンあり）。

## データ

- 防具・スキル・装飾品データ: [RiseSim](https://github.com/EXXXI/RiseSim)（MIT License, © 2022 EXXXI）の CSV（サンブレイク Ver.16 対応）を `tools/convert.py` で `data/master.json` に変換しています。元CSVとライセンスは `data/source/` にあります。
- データを更新する場合は `data/source/MHR_*.csv` を差し替えて `python3 tools/convert.py` を実行してください。
- 登録した手持ちデータはブラウザの localStorage に保存されます（端末ごと・サーバーには送信されません）。

## 開発

```bash
node test/solver.test.mjs   # 探索エンジンのテスト（実データ使用）
```

| パス | 役割 |
| --- | --- |
| `index.html`, `css/style.css` | 画面 |
| `js/app.js` | UI（登録・検索・結果・ソート） |
| `js/store.js` | 保存・バックアップ |
| `js/solver.js` | 探索エンジン（UI非依存） |
| `js/worker.js` | 探索を Web Worker で実行 |
| `sw.js`, `manifest.webmanifest` | オフライン対応・ホーム画面追加 |
