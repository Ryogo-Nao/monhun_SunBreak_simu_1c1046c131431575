# 変更の取り込み方と戻し方

Claude が作業する branch は `claude/○○` という名前です。アプリの公開（GitHub Pages）は **`claude/confident-allen-rnj891`** から行われます（`.github/workflows/pages.yml`）。公開用 branch に取り込むと、自動で公開処理が走ります。

## 取り込み方

### GitHub の画面で（おすすめ）

1. リポジトリの「Pull requests」→「New pull request」
2. **base**: `claude/confident-allen-rnj891`（公開用）／ **compare**: 作業 branch
3. 「Create pull request」→ 「Files changed」で変更内容を確認
4. 「Merge pull request」→「Confirm merge」（方法は **Create a merge commit**）
5. 「Actions」タブで「Deploy to GitHub Pages」に緑のチェックが付けば反映完了
6. スマホのホーム画面アプリは、一度完全に終了して開き直す

Claude に「取り込んで」と頼めば、この手順を代行します。

## 戻し方

「戻す」（revert）は、変更を打ち消す新しいコミットを足す方法です。履歴は消えないので、戻した後で取り込み直すこともできます。

### A. プルリクエスト単位で丸ごと戻す（GitHub の画面だけで可能）

1. 取り込んだプルリクエストを開く
2. 下の **「Revert」** ボタンを押す（取り消し用のプルリクエストが作られる）
3. そのプルリクエストを「Merge pull request」→「Confirm merge」
4. 公開処理が終われば、取り込み前の状態に戻る

### B. 一部のコミットだけ戻す（コマンド）

```bash
git switch claude/confident-allen-rnj891
git pull
git revert --no-edit <戻したいコミット>
git push
```

### C. 取り込み（マージコミット）を丸ごと戻す（コマンド）

```bash
git revert --no-edit -m 1 <マージコミット>
git push
```
